# KARAFAKİ — restaurant website design concept

Live: **https://erhanerogluant.github.io/karafaki-concept/**

A design concept for a **fictional** meyhane (rakı and meze restaurant) in Berlin. Name, menu,
prices and location are examples; no bookings are taken.

This repository contains only the compiled static site served by GitHub Pages. The source code
is not public.

Photos are illustrative open-licence and stock images, not of any restaurant; every image, video
and sound is credited on the site's imprint page (`/karafaki-concept/en/imprint/`). Cropped
versions of CC BY-SA images are shared under the same licence. © Design and code: all rights
reserved.
